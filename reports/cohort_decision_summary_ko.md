# 학습 데이터 확정 방향 — 결정 요약

2026-10-20. **단백질이 같다는 이유로 여러 실험을 합치지 않고, 실험 조건별로 데이터를 구성하기로 했다.** 선정 규칙을 설정 파일로 고정하고 실제 자료에 적용했다.

1. 주 과제는 인간 정상형(WT) EGFR의 생화학 IC50 예측이다. 변이형·세포 실험·Ki/Kd는 별도 자료로 둔다.
2. 같은 실험의 반복값만 출처 검토 후 대표값으로 정리한다. 다른 실험의 같은 분자를 일괄 평균하지 않는다.
3. 실험을 합치려면 원문 프로토콜 확인과 공통 화합물의 값 일치 검증이 모두 필요하다. 조건 결측끼리는 같다고 처리하지 않는다.
4. 문헌의 0.5 log·75%·공통 화합물 5개 등의 선례를 참고하고, 불확실성과 편향 검사를 더했다. 이 조합은 우리 프로젝트의 운영 기준이며 국제 표준은 아니다.

현재 결과는 다음과 같다.

| 검사 | 결과 |
|---|---|
| WT 후보 전체 | 50건·6개 실험 보존 |
| 공개 원문 방법·수치 확인 | 1개 실험·22건 |
| 원문 표의 화합물 번호와 ChEMBL 활동 연결 | 22/22건 일치 |
| 실험 간 비교 | 15쌍 모두 공통 구조 0~1개 |
| 합동 학습 데이터 승인 | 0쌍 |
| 보류 자료 확대 검토 목록 | 37개 실험·277건, 공개 PMC 경로 4개 문헌 확인 |

22건은 동일 실험의 조건 확인 파일럿으로 저장했다. 단백질 구성체·효소 농도 등은 여전히 미확인이고, 표본 수와 활성 범위도 제한적이므로 넓은 EGFR 성능 평가 데이터로 확정하지 않았다. 나머지 5개 문헌은 실험 방법 원문에 접근하지 못해 보류했다. 자료가 잘못됐다는 판정은 아니다.

이제 고유 구조가 많은 단일 실험과 공개 원문이 있는 실험을 우선 검토한다. 조건이 검증된 충분한 단일 프로토콜 자료를 확보하거나, 실험 간 호환성 근거를 확보한 뒤 최종 학습/검증/test 구성을 고정한다. 성능을 보고 자료를 선택하지 않는다.
