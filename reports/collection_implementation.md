# ChEMBL 전체 수집기 구현·검증 기록

구현·검증일: 2026-10-20. 실행 환경은 기존 Python 3.12.14·macOS arm64 P0 환경이다. [패키지 고정 기록](p0_environment_validation.md)을 유지했으며 수집기 구현 과정에서 추가 패키지를 설치하지 않았다.

## 구현한 기능

- `collect`: 인간 EGFR IC50 측정·연결 assay·molecule·document의 원 응답 수집.
- `--resume`: 동일 옵션·release를 확인하고 보관된 성공 응답을 재사용.
- `--max-pages`: 제한 실행을 `preview_complete`로 구분.
- `verify-collection`: 원 JSON·분석 Parquet 5개를 네트워크 없이 재검증.
- 원자적 파일 저장, 매니페스트·checkpoint, 실행 폴더 잠금, 다른 실행의 기존 분석 파일 보호.
- 페이지 범위·정렬·ID 중복·건수·다음 페이지 필터·상세 ID 집합·연결 행 수 검사.
- 재시도·Retry-After·실패·중단 기록과 대기 중 요청 취소.
- 원 응답의 변이·부등호·품질 정보 보존. 문헌은 측정과 assay에 등장한 ID의 합집합을 수집.
- 실행별 코드 해시·Python·패키지 버전, 원 응답 시각·SHA-256, ChEMBL 출처·라이선스 기록.

## 자동 테스트

`PYTHONPATH=src .venv/bin/python -m unittest discover -s tests -q` 결과: **19개 테스트 통과**. 수집·HTTP 테스트 16개와 기존 단위·연구 정책 테스트 3개다.

| 검사 상황 | 확인한 결과 |
|---|---|
| 같은 화합물의 여러 측정 | activity ID를 유지해 행을 합치지 않음 |
| 정확값·부등호·null | 각각 원 표기를 보존 |
| activity에 없는 assay 출처 문헌 | 합집합으로 조회해 보존 |
| 정수 PMID와 결측값 혼합 | `12345`를 `12345.0`으로 바꾸지 않음 |
| 중간 페이지 503 실패 후 재개 | 성공한 첫 페이지를 다시 요청하지 않음 |
| 제한 실행 | 전체 완료와 구분하고 다른 조건으로 재개 거부 |
| 중복 activity ID·잘못된 건수 | 실패 상태로 종료 |
| 상세 ID 누락·다음 페이지 자원 경로 변경 | 성공으로 처리하지 않음 |
| 실행 도중·재개 시 release 변경 | 이전 release와 혼합하지 않음 |
| 보관 원 응답 변조 | 해시·크기 검사에서 검출 |
| 분석 테이블 내용 변경 후 해시만 갱신 | 원 응답에서 재구성한 표와 대조해 검출 |
| 미완료 실행 오프라인 검증 | 완료로 인정하지 않음 |
| 같은 실행의 동시 쓰기 | OS 잠금으로 거부 |
| 소유 기록 없는 기존 분석 폴더 | 사용자 파일을 덮어쓰지 않음 |
| 429·400·깨진 JSON | 대기·재시도·즉시 실패를 구분 |

모의 서버를 사용한 검사는 네트워크를 호출하지 않는다. 합성 자료의 결과를 실제 ChEMBL 규모나 모델 성과로 보고하지 않았다.

## 실제 API 실행

- [소량 실행 결과](collection_chembl_preview_20261020.md): 측정 10건·분자 6개·assay 5개·문헌 3개. 원 응답 저장·상세 묶음 조회·Parquet·오프라인 대조를 통과했다.
- [전체 실행 결과](collection_chembl_full_20261020.md): 최종 건수·관계 분포·수집 완료 상태는 이 보고서와 대응 JSON을 기준으로 한다.
- 전체 실행은 `complete`: 측정 26,600건, 분자 14,776개, assay 2,425개, 문헌 1,299개를 확보했다. 측정이 직접 가리킨 문헌은 1,298개이며 assay 연결에서 추가 문헌 1개를 확보했다.
- 최종 원 응답 432개·Parquet 5개를 검증했다. 이전 미확인 관계 11건은 `>>`로 확인했고 정확값으로 바꾸지 않았다.
- [실제 재개 검증](collection_resume_validation.json): 첫 실행의 원 응답 429개를 모두 재사용했고 기존 해시가 일치했다. 새 API 요청은 시작 status·종료 건수·종료 status 3개였다. 코드 검토에서 보완한 nullable 식별자 처리를 적용해 최종 표를 재생성했고 문헌 1,299개의 PMID를 원 응답과 대조했다.

## 완료 범위와 한계

수집 완료는 지정한 API 조건의 자료와 연결·파일이 일관된다는 기술적 판정이다. confidence 9·변이 미주석 자료 등을 학습 적격으로 자동 분류하지 않았다. 구조 정규화·반복 측정 요약·scaffold 분할·라벨 생성·모델 학습도 수행하지 않았다.

시작·종료의 release와 건수 대조는 API의 트랜잭션 스냅샷 보장이 아니다. 라이브 API 수집과 공식 고정 release dump를 구분한다. 실제 학습 코호트 선택은 후속 전체 데이터 감사·실험·변이 검토로 결정한다.
