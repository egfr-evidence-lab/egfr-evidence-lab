# 지원 기업 적합성·EGFR 기준·도메인 학습 범위 점검

검토일: 2026-10-20. 대상: 비엔제이바이오파마 AI 연구원 공고와 현재 EGFR Evidence Lab 구현.

후속 상태: 이 문서는 아래 최초 검토 시점의 기록입니다. 이후 209건을 검토·보류하고 단일 assay 22건으로 교육용 Dummy·RF를 실행했습니다. 최신 모델 결과·한계는 [후속 보고서](apsel_review_and_baseline_ko.md)를 따릅니다. 딥러닝·저자 모델 재현·Agent·배포는 여전히 미실행입니다.

## 판단

**기업의 요구 방향과 프로젝트 설계는 잘 맞는다. 현재 증거는 데이터 수집·정제·출처 검증에 집중되어 있고, 딥러닝·논문 재현·Agent·클라우드 역량의 구현 증거는 아직 없다.** 다음 포트폴리오 개선의 중심은 완결된 예측·평가 결과와 근거 조회 데모다.

확인한 공식 지침·논문에서는 EGFR의 모든 실험, 화합물, 예측 모델에 공통 적용되는 숫자 합격선을 찾지 못했다. **실험 품질, 화합물 품질, 데이터 병합 기준, 모델 성능**을 구분해 각각 근거를 제시해야 한다. 기존의 0.5 log·75%·Wilson 하한 등은 프로젝트 정책이며 기업의 채용 기준이나 EGFR 국제 표준이 아니다.

## 2. 기업 연구 방향과 얼마나 가까운가

연구 주제인 EGFR은 공개 회사 연구와 연결된다. 공동연구사 한독은 2024년 EGFR 변이 분해제 HDBNJ-2812의 연구를 발표했고, 2026년에는 BNJ 소속 저자들이 참여한 HBE-843 EGFR PROTAC 논문이 발표됐다. 두 이름이 같은 화합물이라는 근거는 확인하지 않았으므로 동일시하지 않는다. [한독 공식 발표](https://www.handok.co.kr/en/board/en_pressView?idx=4276&lang=en&listSize=9&page=1&type=media), [HBE-843 원 논문](https://doi.org/10.1002/ardp.70193)

HBE-843의 출판사 초록과 Europe PMC 메타데이터에서 DOI·PMID·저자 소속·연구 주제를 대조했다. 초록에는 변이 보유 세포에서 GI50 26–103 nM, DC50 1.9–18 nM, Dmax 90% 초과가 보고돼 있다. 이는 저자의 전임상 결과이며 우리의 재현 결과가 아니다. 해당 세포별 값·처리 시간·대조 실험의 원문/SI 전체 검토는 하지 않았다. [출판사 초록](https://onlinelibrary.wiley.com/doi/10.1002/ardp.70193)

기업 연관성을 높일 추가 주제는 **WT와 내성 변이를 구별하고, 단백질 억제와 분해를 구별하는 근거 사례**다. 첫 단계는 1개 논문의 근거 카드면 충분하다. 모든 변이의 모델을 추가하거나 분해제 생성 모델까지 확장할 필요는 없다.

## 3. 어떤 기준은 문헌에 있고, 무엇에 쓸 수 있는가

| 평가 대상 | 확인한 기준·원칙 | 올바른 사용 | 사용하면 안 되는 해석 |
|---|---|---|---|
| 실험 품질 | kinase 지침의 Z′ >0.5, 대조군 CV <10% 등 바람직한 조건 | 실험 대조군의 분리·반복성을 검토 | 모델 MAE 합격선, 서로 다른 assay 병합 보증 |
| 연구용 chemical probe | SGC의 생화학 활성 <100 nM, 관련 단백질 대비 ≥30배 선택성, 세포 활성 ≤1 µM 등 | 연구 도구 화합물의 근거 카드 | EGFR 신약 승인 기준, 회귀 학습행의 일괄 필터 |
| 공유결합 억제제 | 시간 의존성과 기전 지표 검토. 일반화된 kinact/KI 합격값은 제안되지 않았다는 2023년 논의 | 반응 시간·표적 결합/선택성 근거 확인 | endpoint IC50 하나로 서로 다른 기전 통합 |
| 분해제 probe | 2023년 Perspective의 DC50 <1 µM, Dmax 약80% 이상 등 제안 | 분해 효과·선택성·기전·독성 간격의 근거 검토 | 회사 채용 합격선·임상 유효성 보증 |
| QSAR 예측 모델 | OECD의 endpoint·알고리즘·적용 범위·통계 검증·가능한 기전 해석 | 목적에 맞는 모델 카드·검증 설계 | EGFR 공통 R²·MAE 숫자 합격선 |
| 우리 데이터 병합 | 공통 구조·조건·일치도·편향 기준 | 엄격한 참조 코호트의 운영 정책 | 외부에서 이미 검증된 EGFR 표준 |

실험 지표 근거는 [NCATS/Eli Lilly kinase 지침](https://www.ncbi.nlm.nih.gov/sites/books/NBK91991/)이다. Z′는 효과가 없는 대조군과 효과가 확실한 대조군이 얼마나 구별되는지 평가한다. 현재 보관한 IC50 결과만으로는 이를 계산할 수 없으므로 `미확인`으로 남겨야 한다. Z′ 하나만으로 품질을 판정하지 말라는 지침도 있다.

SGC-UNC는 위 chemical probe 기준에 비활성 유사체 대조약과 공개 이용 가능성도 포함한다. 관련 단백질군 대비 30배라는 기준을 WT/변이 선택성에 자동 대입하지 않는다. WT/변이 선호도는 해당 연구 질문과 동일 조건에서 별도로 평가한다. [SGC 공식 기준](https://www.sgc-unc.org/main-st)

Hartung 등의 2023년 논의는 공유결합·분해제에 맞춘 **저자 제안 기준**이다. 단일 IC50의 시간 의존성 한계, 표적별 차이, 분해 효율과 세포 독성의 구분을 강조한다. Dmax·DC50만으로 전체 기준을 통과했다고 볼 수 없다. [원 Perspective](https://doi.org/10.1021/acs.jmedchem.3c00550)

OECD 원칙은 화학 구조로 성질을 예측하는 QSAR 검증을 위한 일반 틀이다. EGFR 임상 모델 인증을 뜻하지 않는다. 다음 다섯 가지로 포트폴리오 검증표를 구성할 수 있다: 무엇을 예측하는가, 어떻게 계산하는가, 어떤 분자에 적용되는가, 처음 보는 자료에서도 얼마나 맞는가, 생물학적으로 어떤 해석이 가능한가. [OECD 공식 안내](https://www.oecd.org/en/topics/sub-issues/assessment-of-chemicals/quantitative-structure-activity-relationships-project.html), [원칙 원문](https://www.oecd.org/content/dam/oecd/en/topics/policy-sub-issues/assessment-of-chemicals/oecd-principles-for-the-validation-for-regulatory-purposes-of-quantitative-structure-activity-relationship-models.pdf)

## 4. 현재 기준의 장점과 보완점

장점은 비교 불가능한 값을 섞지 않고, 단위·변이·문헌 연결과 제외 이유를 남긴다는 점이다. 공개 원문 22건을 화합물 번호와 연결한 검증은 실제로 보여줄 수 있는 증거다.

보완할 부분도 있다.

- 13개 조건의 완전 일치는 아주 보수적인 참조층을 정의하는 정책이다. 조건이 다르거나 기록이 부족한 자료 전부가 오류라는 뜻은 아니다. 근거 등급을 나누어 보류 자료를 추적하고, 검증된 bridge/조건 보정이 가능한지는 별도 연구로 다룬다.
- Wilson 하한 75%, 큰 차이 비율 10%, 편향 CI ±0.3의 조합은 우리 기준이다. 실측으로 검증된 보편 합격선이라고 표현하지 않는다. 화학 유사체 간 의존성도 검토한다.
- 병합 승인 0쌍은 **현재 WT 후보 50건의 15쌍**에 관한 결과다. 전체 26,600건에서 모든 비교가 불가능하다고 일반화하지 않는다.
- 분자 유형 결측은 실제 비소분자 판정과 다르다. 원문과 구조 검토로 복구할 수 있는 자료를 별도로 다룬다.
- 엄격한 데이터 22건을 확보한 것과, 넓은 분자 공간의 학습·평가에 충분한 것은 다르다. 공개 benchmark 재현을 별도 트랙으로 진행하면 데이터 감사를 유지하면서 학습 구현 경험도 만들 수 있다.

특히 100 nM 기준은 학습 필터로 일괄 적용하지 않는다. 직접 계산하면 현재 WT 후보 50건 중 45건, 파일럿 22건 중 21건이 100 nM 미만이다. 이것만 남기면 약한 화합물과 대조약 일부를 지우고 활성 범위를 줄일 수 있다. 높은 활성을 갖는 연구 도구의 기준과, 다양한 활성값을 예측할 학습 데이터의 구성은 목적이 다르다.

## 5. 포트폴리오에 추가할 우선순위

아래는 공고와 현재 구현을 대조해 내린 제안이며 회사의 채점표가 아니다.

| 순서 | 추가 산출물 | 보여줄 역량 | 완료 판단 |
|---|---|---|---|
| 1 | 확정 데이터 + Dummy/Morgan-RF의 최소 완결 실험 | ML 기본·통계·바이오 데이터 | 누출 검사, 고정 분할, 기준 모델 대비 오차·95% 구간, 데이터 한계 |
| 2 | 같은 분할·튜닝 예산의 D-MPNN 비교 | 딥러닝 | 모델·seed·소요 시간·오차·실패 사례를 나란히 기록. DL 우세를 사전 가정하지 않음 |
| 3 | 저자 공개 benchmark 1개 제한적 재현 | 논문 구현·재현 | 원 데이터·분할·commit·버전·지표·원 결과와 차이. 현재 SAMPL 후보부터 실제 원 설정 확인 |
| 4 | 회사 관련 EGFR 내성·분해제 근거 카드 1개 | 도메인 이해·문헌 해석 | WT/변이, IC50/GI50/DC50/Dmax, 근거 위치와 미확인 조건 구분 |
| 5 | 측정 조회·문헌 검색·예측 도구를 쓰는 작은 Agent | Agentic AI | 고정 질의 집합에서 도구 선택·인용 정확성·정보 부족 처리 평가 |
| 6 | 단일 컨테이너의 추론 API와 클라우드 실행 기록 | 클라우드 | 모델 버전, 실제 요청·응답, 오류·재시작·로그·지연·비용 확인 |

1~3은 모델링의 중심 증거다. 4는 작은 범위로 병행할 수 있다. 5~6은 검증된 예측기를 연결하는 순서가 적절하다. 22건을 억지로 쪼개 강한 성능 주장을 하거나, 도킹·분자 생성·거대한 다중 Agent·전체 PK 예측을 한꺼번에 추가하지 않는다.

Scaffold 분할은 비슷한 골격의 화합물이 학습과 시험에 섞이는 문제를 줄이려는 평가다. 연도 정보가 적절하면 시간 분할도 보조로 확인한다. 어느 하나만 실제 미래 성공을 보증하지 않는다. [Yang 등 원 논문](https://pmc.ncbi.nlm.nih.gov/articles/PMC6727618/)

현재 계획된 `chemprop_benchmark`는 v1용 자료다. EGFR 주 실험에서 v2를 실행한 결과와 구분하고, 원 데이터·분할·버전을 맞춘 범위만 재현으로 설명한다. [저자 benchmark](https://github.com/chemprop/chemprop_benchmark)

모델의 완료 기준은 임의의 MAE 0.5나 R² 0.8 하나가 아니다. 같은 시험 자료에서의 기준 모델 대비 차이, scaffold·문헌별 실패, 라벨의 반복 오차, 적용 범위를 함께 보고한다. 작은 표본에서는 신뢰구간이 넓다는 사실도 결과에 포함한다.

## 6. 의료 도메인이 부족해도 이해할 수 있는 범위인가

**공고에 맞춘 공개 데이터·모델링 포트폴리오는 비의료 전공자도 접근 가능한 범위다.** 공고는 의학 학위나 임상 진료 경험을 요구하지 않고 Python 분석·ML·전처리·통계 역량을 요구한다. 다만 현재 사용자의 이해도를 실제 시험한 것은 아니므로, 아래 설명을 스스로 재구성할 수 있는지 확인하는 방식이 적절하다.

필요한 첫 학습 범위는 임상 의학 전체보다 **분자 약리와 실험 데이터의 정의**에 가깝다.

| 개념 | 쉬운 설명 | 설명할 수 있어야 하는 점 |
|---|---|---|
| EGFR | 세포 신호를 전달하는 단백질 | 정상형과 변이형을 같은 대상으로 취급하지 않는 이유 |
| 억제와 분해 | 기능을 막는 작용과 단백질 양을 줄이는 작용 | 서로 다른 결과값을 같은 정답으로 합칠 수 없는 이유 |
| IC50 | 특정 조건에서 억제 효과의 절반 수준에 해당하는 농도 | 작은 값의 의미와 조건·시간에 따른 변화 |
| pIC50 | 농도를 몰 단위로 음의 로그 변환한 값 | 값이 1 다르면 농도가 10배 다름 |
| GI50 | 세포 성장 억제의 농도 지표 | 단백질 효소 실험의 IC50와 구별 |
| DC50·Dmax | 분해 농도 지표·최대 분해율 | 처리 시간·세포·원문 정의까지 확인 |
| 선택성 | 여러 표적 중 원하는 표적에 더 강하게 작용하는 정도 | 약효·안전성과 동일한 뜻이 아님 |
| 실험 맥락 | ATP·기질·구성체·시간·온도·측정법 | 같은 물질의 값이 다른 논문에서 달라도 곧바로 오류가 아닌 이유 |
| 적용 범위 | 모델이 충분한 근거를 가진 화학 구조의 범위 | 낯선 분자의 예측을 보류·낮은 신뢰도로 표시할 이유 |

IC50를 낮추면 환자에서 더 좋은 치료제가 된다고 곧바로 결론 내릴 수 없다. 세포 내 접근, 다른 표적 작용, 노출과 독성 등 다른 근거가 필요하다. 이 포트폴리오는 치료 권고가 아닌 전임상 공개 데이터 분석을 범위로 둔다.

## 7. 이해도 자가 점검과 답

아래 문항은 이 보고서의 학습 점검이며 기업의 합격 시험이 아니다. 답을 외우기보다 이유와 출처를 설명한다.

1. **10 nM과 100 nM의 pIC50는 각각 얼마인가?** → 8과 7. 해당 조건에서 10 nM 쪽이 더 낮은 농도에 같은 억제 수준을 보였다.
2. **정상형과 변이형에서 같은 약의 값이 다르면 오류인가?** → 아니다. 단백질 상태가 다르다. 같은 실험 조건인지 먼저 확인한다.
3. **단백질 IC50가 작으면 암세포 성장도 반드시 잘 막는가?** → 아니다. 단백질 수준 억제와 세포 수준 결과는 다르다.
4. **DC50 10 nM과 IC50 10 nM을 같은 라벨로 학습해도 되는가?** → 안 된다. 측정한 현상이 다르다.
5. **두 assay의 ATP 값이 모두 비어 있으면 같은 조건인가?** → 알 수 없다. 같은 결측은 같다는 증거가 아니다.
6. **WT/변이 IC50 비율이 크면 임상 안전성이 입증되는가?** → 아니다. 비교 조건과 목적을 확인해야 하며 독성·노출 등의 별도 근거가 필요하다.
7. **100 nM 미만 자료만 모으면 회귀 모델 데이터가 항상 좋아지는가?** → 아니다. 약한 화합물·대조약을 배제하고 라벨 범위를 좁힐 수 있다.
8. **모델 MAE가 0.5면 모든 예측이 약3.16배 이내인가?** → 아니다. 개별 pIC50 차이0.5는 약3.16배지만 MAE는 평균 오차라 개별 보장은 아니다.
9. **원문 22개 수치가 일치하면 원 논문 모델을 재현한 것인가?** → 데이터 연결·전사 검증이다. 모델 재현에는 원 데이터·분할·설정·평가의 실행 대조가 필요하다.

학습 순서는 단위·endpoint → 정상형/변이·실험 조건 → 실제 원문 한 편의 표 읽기 → 모델 분할·평가 → 분해제 사례를 권장한다. 각 단계에서 본인 말로 2분 설명하고 위 사례에 적용해 본다. 배경지식이 필요한 항목은 원문·실험 전문가와 확인하며 모르는 부분은 미확인으로 기록한다.

## 8. 면접에서 사용할 수 있는 현재 설명

“ChEMBL 인간 EGFR IC50 26,600건을 수집하고 원 응답·버전·해시를 보존했습니다. 실험·변이·단위·품질을 감사하고 공개 원문 한 실험의 22개 값을 화합물 번호와 연결해 대조했습니다. 현재 후보의 실험 간 공통 화합물이 부족해 합동 학습 데이터는 보류했고, 기준 모델과 D-MPNN의 비교·논문 재현은 후속 단계입니다.”

현재 모델 성능, 신약 발견, 논문 성능 재현, 실제 배포를 완료했다고 쓰지 않는다. 회사의 임상 성과나 내부 모델을 재현했다고도 설명하지 않는다.
