## 어떤 단위로 학습 데이터를 구성할 것인가

하나의 관측을 **화학 구조 × 표적·변이 × 실험 프로토콜 × endpoint**로 정의한다. 목표는 “인간 WT EGFR의 조건이 명시된 생화학 IC50”다. 같은 화합물의 실험별 결과는 별도 관측으로 유지한다.

| 데이터 층 | 포함 범위 | 사용 |
|---|---|---|
| 원자료 | 26,600건, 부등호·결측·품질 플래그 포함 | 출처 추적·재검토 |
| 조건 확인 파일럿 | 원문 방법·화합물 번호·수치가 연결된 단일 assay | 처리 파이프라인·SAR 검토 |
| 확정 학습 코호트 | 동일 프로토콜 또는 아래 호환성 관문을 통과한 assay 묶음 | 주 모델 개발, 현재 미생성 |
| 확장·민감도 자료 | 유래·구조·프로토콜 근거 일부 보류 | 원문 확보 후 별도 재판정 |

WT와 변이, 생화학 효소 실험과 세포 증식/생존, IC50와 Ki/Kd를 각각 분리한다. 공유결합 설계 계열과 비공유결합 설계 계열도 맥락 없이 합치지 않는다. 공유결합 설계라는 논문의 설명을 모든 개별 화합물의 시간 의존성이 실증됐다는 뜻으로 사용하지 않는다.

ChEMBL의 confidence 9는 표적 연결의 신뢰도다. 모든 실험 조건이 같다는 표시는 아니다. 변이 미기재나 두 실험의 조건 결측이 서로 같다는 이유로 정상형·호환성을 승인하지 않는다. [ChEMBL 공식 FAQ](https://chembl.gitbook.io/chembl-interface-documentation/frequently-asked-questions/chembl-data-questions)

## 다른 연구·프로젝트는 범위를 어떻게 정했는가

| 근거 | 실제 선정·검증 방식 | 이번 프로젝트에 적용할 점 |
|---|---|---|
| Papyrus / Papyrus++ (Béquignon 등, 2023) | IC50·EC50를 각각 처리하고, 반복값이 중앙값에서 0.5 log 초과 벗어나면 비일치로 판정. 단일 관측은 다른 자료에서 75% 일치하는 assay인지 검토 | 반복 일치도와 assay 재현성을 검사. 0.5·75%는 이 프로젝트의 선례이지 보편 표준이 아님 |
| Landrum·Riniker (2024), 공개 overlapping_assays 프로젝트 | confidence·문헌·변이·실험 메타데이터를 선별하고 공통 화합물의 값 차이를 분석 | 메타데이터 일치만으로 끝내지 않고 같은 화합물의 실측 차이를 확인 |
| Nelen 등 (2025), 공개 ChEMBL_MatchedPairsAnalysis | 공통 화합물 최소 5개와 추가 조건을 사용하고, 절대 차이·0.3/1.0 log 초과 비율을 분석 | 공통값 부족을 실패한 검증과 구분. 상대 SAR 일치가 절대 IC50 호환성을 보증하지 않음 |

Papyrus의 모델 예시에서는 활성·비활성 화합물이 각각 30개보다 적거나 활성 범위가 2 log 미만인 표적을 제외했다. 이는 그 연구의 모델링 설계다. 이 수를 넘으면 학습에 충분하다거나, 회귀에 활성/비활성 30개씩이 보편적으로 필요하다는 주장은 하지 않는다. [논문 방법](https://link.springer.com/article/10.1186/s13321-022-00672-x), [공개 코드](https://github.com/CDDLeiden/Papyrus-scripts)

2024년 연구의 최소 정제 IC50 비교에서는 약 64%가 0.3 log, 27%가 1 log 넘게 달랐다. 메타데이터를 더 엄격히 맞춰도 혼합 오차가 완전히 없어지지 않았다. 따라서 “같은 EGFR이면 모두 합친다”를 기본값으로 삼지 않는다. [원 논문](https://doi.org/10.1021/acs.jcim.4c00049), [저자 코드·데이터](https://github.com/rinikerlab/overlapping_assays)

저자 notebook도 내려받아 확인했다. 기본 인자는 `minOverlap=5`이지만 SQL은 `ovl>:minOverlap`이므로 그 코드 경로는 공통 화합물 **6개 이상**이다. 2025년 논문의 “5개 이상” 표현과 차이가 있어 그대로 복제했다고 주장하지 않는다. 우리 정책은 5개를 **최소 진단 시작점**으로 명시하며 불확실성 관문을 추가했다. 코드 파일 SHA-256은 문헌 수집 매니페스트에 보관했다. [원 notebook](https://github.com/rinikerlab/overlapping_assays/blob/main/ChEMBL32_OverlappingIC50s-paper.ipynb), [2025년 연구](https://doi.org/10.1186/s13321-025-00956-y)

추가로 AssayMatch는 실험 설명과 데이터 기여도로 학습 자료를 선택하는 공개 프로젝트다. 원문은 2025년 preprint이므로 확립된 표준으로 취급하지 않았다. 학습 후 성능이 좋은 자료를 임의 선택하기보다 선정 절차와 검증 자료를 분리한다는 참고 사례로만 사용한다. [저자 preprint](https://arxiv.org/abs/2511.16087), [공개 코드](https://github.com/Ozymandias314/AssayMatch)

## 반드시 확인할 실험 조건

NCATS/Eli Lilly의 Assay Guidance Manual은 kinase 실험에서 ATP·기질·단백질 형태·반응 시간·첨가 순서·검출법을 함께 고려한다. 특히 ATP 경쟁 및 느린 결합에서는 ATP 농도와 사전 반응이 관측 IC50에 영향을 줄 수 있다. [공식 실험 지침](https://www.ncbi.nlm.nih.gov/sites/books/NBK91991/)

| 항목 | 비교 기준 | 결측·차이가 있으면 |
|---|---|---|
| 생물학적 표적 | 인간 WT EGFR, 서열/구성체·태그·변이 확인 | 엄격한 병합 보류 |
| 단백질 | 공급원, 효소 농도, 도메인·활성화 상태 | 원문·SI·제품 catalog 근거 확인 |
| ATP·기질 | 최종 ATP 농도, 기질 종류·농도, 가능하면 ATP Km | 임의 환산·정규화 금지 |
| 시간·온도 | 사전 반응, 효소 반응, 첨가 순서, 온도 | 공유결합·느린 결합 계열은 특히 분리 |
| 완충액 | pH, Mg/Mn, 환원제·detergent 등 | 차이 기록 후 호환성 재검토 |
| 측정법 | HTRF, mobility shift, Z-Lyte, ELISA, ATP 검출 등 | 검출법 이름만으로 동일 endpoint라고 승인하지 않음 |
| 라벨·품질 | 정확 양수 IC50, 몰 단위, 원문 표·화합물 번호·단위 일치 | 부등호는 별도 자료, 품질 경고는 보류 |

경쟁적·가역적 억제의 제한된 가정에서는 `IC50 = Ki × (1 + [ATP]/Km)` 관계가 성립한다. 그러므로 ATP 농도·Km·기전이 없는데 같은 수식으로 보정하면 안 된다. 시간 의존 공유결합 억제의 endpoint IC50에 이를 일괄 적용하지 않는다. [실험 지침의 기전 설명](https://www.ncbi.nlm.nih.gov/sites/books/NBK91991/)

## 이번 프로젝트에서 고정한 병합 지표

아래 수치의 조합은 **문헌을 참고해 정한 프로젝트 운영 기준**이다. EGFR에서 타당성이 검증된 국제 합격선은 아니다. 기준은 미래 모델의 최종 test 성능을 보고 조정하지 않는다.

| 관문 | 사전 고정 기준 | 근거·역할 |
|---|---|---|
| 조건 관문 | 원문 조건의 핵심 항목이 확인되고 일치. 결측끼리 일치 처리 금지 | 실험 지침 및 max-curation 접근을 더 명시적으로 적용 |
| 공통 구조 수 | assay 쌍마다 최소 5개 | 위 공개 연구의 출발점; 충분성 보증 아님 |
| 값 일치도 | `abs(ΔpIC50) ≤ 0.5` 비율 ≥75% | Papyrus의 수치를 참고하되 **쌍간 차이**로 정의한 우리 지표. 중앙값 편차와는 다른 통계 |
| 일치도 불확실성 | 위 비율의 Wilson 95% 구간 하한 ≥75% | 소수의 공통 양성 대조만으로 승인하지 않기 위한 추가 기준 |
| 체계적 편향 | 중앙값 signed Δ의 bootstrap 95% 구간 전체가 −0.3~+0.3 안 | 약 2배 규모 차이의 선례를 참고한 추가 기준 |
| 큰 불일치 | `abs(ΔpIC50) > 1` 비율 ≤10% | 문헌의 1 log 진단 지표에 적용한 프로젝트 허용치 |
| 묶음 승인 | 포함 assay의 모든 쌍 통과 | A-B·B-C 통과만으로 A-C를 승인하지 않음 |

Wilson 구간은 [NIST 통계 지침](https://www.itl.nist.gov/div898/handbook/prc/section2/prc241.htm)을 사용했다. 공통 화합물 5개가 모두 일치해도 95% 하한은 약 56.6%여서 승인되지 않는다. Wilson/화합물 bootstrap에는 관측 간 의존성 가정의 한계가 있다. 유사체 계열이 몰려 있으면 scaffold·계열 단위의 불확실성과 화학적 범위를 추가 검토해야 한다. 이 숫자만 통과했다고 생물학적 동등성이 증명되는 것은 아니다.

현재 15쌍은 모두 공통 구조 부족으로 진단 관문을 넘지 못했다. 14쌍은 공통 구조 0개, 한 쌍은 osimertinib 1개다. 이 한 쌍의 IC50는 142.1과 70 nM이며 차이는 약 0.3075 pIC50다. 하나의 기준약으로 다른 화합물 전체의 실험 호환성을 판단하지 않았다.

## 실제 원문 검토: CHEMBL4258549

Chen 등의 [원문](https://pmc.ncbi.nlm.nih.gov/articles/PMC6083791/) `Materials and methods / EGFR kinase activity assay`에서 ATP 5 µM, poly(Glu,Tyr) 4:1, 37°C·60분 ELISA 조건을 확인했다. 정확한 구성체 서열·효소 농도·별도 사전 반응 시간·ATP Km은 확인되지 않아 결측으로 남겼다. 논문은 공유결합 억제제 설계를 다룬다.

Tables 1·3의 화합물 번호 → ChEMBL `compound_record` → 보관 원 활동 ID를 연결해 WT 농도 **22/22건 일치**를 확인했다. 세포 활성의 Table 2와 변이형 열을 사용하지 않았다. 값만 같은 화합물을 임의로 대응하지 않았다. 표의 ± 값이 SD인지 SEM인지와 반복 횟수는 확인되지 않아 학습 가중치로 사용하지 않았다.

이 실험은 22구조·12 scaffold, pIC50 약 6.847~8.495(폭 1.647)다. 알려진 대조약 1개를 포함한다. 조건 추적·입력 처리용 파일럿으로 고정했으며, 넓은 WT EGFR 화학 공간의 성능을 입증하는 benchmark로 확정하지 않았다.

## 반복값·분할·확정 파일 구성

확정 시 한 행에는 canonical isomeric SMILES, 구조 그룹, 입체정보 제거 비교 그룹, 표적·변이, 프로토콜 ID, 원 activity ID 목록, 문헌·표·화합물 번호, 원 농도·단위·관계, pIC50, 제외 사유, 근거 URL을 포함한다. assay 조건과 문헌 근거는 별도 표로 연결한다.

- 동일 구조·assay·변이·문헌의 반복만 원문 검토 후 pIC50 중앙값으로 대표시킨다. 범위가 0.5 log 초과면 재검토하고 원 행은 보존한다. 다른 실험 간 평균은 하지 않는다.
- 화학 구조는 입체·동위원소를 보존한다. 데이터 분할 때 같은 화합물 및 입체 비교 그룹의 누출을 검사한다. scaffold 분할이 주 평가이고, 문헌/assay 단위 보류 평가는 충분한 자료가 있을 때 보조로 추가한다.
- 실험 호환성 확인에 사용한 공통 구조는 미래 최종 test에서 제외할 보정/검토용 그룹으로 표시했다. 아직 학습/검증/test 행을 배정하지 않았다.
- 표본 수 하나로 충분성을 선언하지 않는다. scaffold·문헌별 수, 라벨 범위·불확실성, 최근접 구조 중복, 학습 곡선, 문헌 보류 성능과 신뢰구간을 보고 평가 계획을 정한다.

## 지금부터 확보할 범위

현재 50건을 합치는 대신 보류된 WT 자료를 **실험별 크기와 원문 접근성** 순으로 재검토한다. unknown origin만으로 보류된 37개 assay와 형식/발현 세포 표기 충돌 자료에서, 원문이 인간 재조합 WT kinase의 동일 프로토콜임을 확인하는 경우만 복구한다. 분자 유형 결측도 구조 검토 후 재판정하며 자동 비소분자로 단정하지 않는다.

다음 확정 관문은 ① 출처 확인된 충분한 단일 프로토콜 자료 확보, 또는 ② 조건·공통 구조 근거가 모두 있는 assay 쌍 확보다. 접근 제한된 5개 문헌의 실험 방법은 미확인으로 유지한다. 접근 실패를 자료가 존재하지 않는다는 증거로 쓰지 않는다.

이를 위해 보류 WT 277건·37개 assay의 검토 우선순위를 실제로 생성했다. Europe PMC 묶음 조회 결과를 DOI·PMID로 연결했고, 4개 공개 PMC 문헌에 연결된 6개 assay를 식별했다. 공개 원문 위치를 찾은 것과 실험 방법을 검토·승인한 것은 다르다. `source_expansion_queue.csv`의 수동 방법 검토 상태는 모두 미완료다.

| 단일 assay 확대 검토 우선순위 | 보류 측정 | 고리 scaffold | DOI |
|---|---:|---:|---|
| CHEMBL3807186 | 40 | 6 | 10.1016/j.bmc.2016.01.003 |
| CHEMBL2439336 | 26 | 6 | 10.1021/jm401045n |
| CHEMBL3385194 | 24 | 12 | 10.1021/jm5014659 |
| CHEMBL3375345 | 21 | 11 | 10.1016/j.bmc.2014.10.038 |

이 순서는 고유 구조 수·scaffold 수·ID 순의 검토 편의를 위한 순서다. 모델 성능을 보고 고른 목록이 아니며, 어느 실험도 원문 확인 전에 학습 자료로 복구하지 않았다.

## 산출물·재현

`data/interim/cohort_review_20261020/`에 조건표, 15개 쌍 검증표, 원문 수치 대조표, 50건 판정표, 22건 파일럿, 37개 확대 검토 우선순위의 CSV 6개와 해시 매니페스트를 저장했다. 문헌 조회 매니페스트도 해당 실행에 스냅샷으로 보존했다. `configs/wt_assay_evidence.json`에는 원문 확인값과 ChEMBL 설명만 있는 값을 구별했다.

```bash
# 네트워크: 6개 문헌 메타데이터·공개 근거 보관

# 오프라인: 기존 출력 보호; 최초 실행에서만 생성

PYTHONPATH=src .venv/bin/python -m unittest discover -s tests -q
```
