# 추가 범위와 실행 순서

2026-10-20 사용자가 [적합성 검토](../reports/portfolio_fit_and_domain_review_ko.md)의 추가 범위를 프로젝트에 포함하고 순서대로 진행하도록 요청했습니다. 상태와 완료 증거는 [범위 설정](../configs/portfolio_scope.json)에 기록합니다. 기존 P0–P5를 확장하며 완료하지 않은 기능을 완료로 바꾸지 않습니다.

| 순서 | 범위 | 실행 조건과 완료 증거 |
|---|---|---|
| M1 / P0–P1 | 학습 데이터 확정 → Dummy·Morgan-RF | 보류 원문 검토, 코호트·분할 고정, 누출 검사, 동일 자료의 오차·CI·적용 범위 |
| M2 / P2 | D-MPNN 비교 | 같은 분할·지표와 명시적 튜닝 예산, seed·시간·환경, RF와 차이 |
| M3 / P2 | 저자 공개 benchmark 1개 재현 | 데이터·분할·commit·설정·환경, 원 결과와 실행 결과 대조 |
| M4 / P0·P3 | 기업 관련 문헌 사례 1개 | 작은 범위로 병행. HBE-843 본문/SI의 지표·조건·대조 실험과 미확인 부분 |
| M5 / P3–P4 | 문헌 검색·도구 선택 Agent | 실제 도구, 개발/최종 질의 분리, 인용·도구 선택·보류·오류 평가 |
| M6 / P5 | 컨테이너 API·클라우드 | 실제 호출·버전·로그·재시작·지연·비용 |

## 현재 수행할 작업

1. 보류 WT 37개 실험·277건의 원문 접근을 규모와 접근성 순으로 검토합니다. PMC 4개 문헌, ACS/RSC 공식 부속자료와 출판사 원문을 우선합니다.
2. 원문·라이선스·URL·수집 시각·해시를 별도 실행 폴더에 저장합니다. 접근 실패는 실패로 기록하고, 원문 미확인을 실험 방법 부재로 바꾸지 않습니다.
3. 표적 유래·변이·실험 형식·ATP·기질·시간·온도·구성체와 수치 표 위치를 근거별로 기록합니다. ChEMBL 설명과 원문 근거를 구별합니다.
4. 복구한 측정은 기존 감사표를 덮어쓰지 않고 검토표에 연결합니다. 원문 확인만으로 서로 다른 실험을 병합하지 않습니다.
5. 고유 구조·scaffold·라벨 범위·문헌 편중으로 학습 범위를 결정합니다. 표본이 부족하면 탐색 분석으로 제한하고, 억지 분할로 넓은 예측 성능을 주장하지 않습니다.

모델 성능을 보고 기준을 바꾸지 않습니다. 임의의 MAE/R² 숫자나 IC50 100 nM을 보편 합격선으로 삼지 않습니다. M1이 조건을 충족하지 못하면 원인과 대안을 기록하고 M2의 강한 성능 주장을 보류합니다. 별도 공개 벤치마크는 EGFR 검증을 대신하지 않습니다.

## 상태 보존

- 첫 실행에서 WT 12개 assay를 접근·검토하고 유래 단독 보류 27건의 근거를 보완했습니다. 수치 11건 중 8건은 반올림 일치, 3건은 별도 곡선 추정치와 차이가 있습니다. 신규 학습 승인 0건입니다.
- 별도 대규모 981건 assay에서 Cot·EGFR 열 혼입 정황을 확인했습니다. [결과 보고서](../reports/wt_expansion_review_ko.md)와 [검토 보류 목록](../configs/source_review_holds.json)을 후속 코호트 선정에 반영합니다.
- Apsel 등 `10.1038/nchembio.117`의 209건을 검토했습니다. 본문 Figure 2a의 8건은 관계 기호·단위·수치가 맞지만 WT·종 유래·전체 SI 표는 미확정입니다. 정확값 167건을 포함해 전체 보류했습니다.
- 기존 단일 assay 22건으로 교육용 Dummy·Morgan-RF를 실제 실행했습니다. 사전에 정한 scaffold 3-fold·3개 seed, 동일 분자 paired 비교, cluster bootstrap·실패 사례를 기록했습니다. [결과·한계](../reports/apsel_review_and_baseline_ko.md), [사용자 실습](11_baseline_practice_ko.md).
- P0·P1은 진행 중, P2–P5는 계획 상태입니다. M1은 주 코호트가 미확정이라 완료가 아닙니다. M4는 초록 카드까지만 진행 중입니다.
- 교육 파일럿의 입력·교차검증 예측·fold 모델은 보관했습니다. 주 코호트·독립 최종 시험 자료·튜닝 결과·배포 결과는 아직 없습니다.
- 22건 원문 대조와 이번 기준 모델 실행은 저자 모델의 재현 완료를 뜻하지 않습니다.
- 데이터·실험·모델·문헌·배포의 실행 매니페스트를 분리하고, 기존 결과와 수동 검토를 보존합니다.

## 다음 작업의 조건

사용자가 실습 실행 후 주 데이터 확보 절차 정리·실행을 요청해 [8단계 절차](12_main_cohort_acquisition_ko.md)를 추가했습니다. [첫 실행](../reports/main_cohort_acquisition_ko.md)에서 전수 재집계·787관측 원문 대조·45건 후보 버전 보존까지 진행했습니다. 현재 우선 해소할 근거는 후보 논문이 명시한2019년 상세 실험법과 단백질 종 유래입니다. 후보와 원 IC50 아닌 억제율4건을 분리했고 신규 학습 승인0건입니다.

사용자는 먼저 실습에서 단위·평균 예측·누출·구간 해석을 직접 확인할 수 있습니다. 주 모델을 확대하려면 Apsel SI의 실제 표와 단백질 정보를 공개 경로 또는 사용자가 확보한 자료로 확인하거나, 원문과 충분히 연결되는 다른 단일 프로토콜 코호트를 확보해야 합니다. 다운로드 실패를 방법 부재로 단정하지 않으며, 보류 자료를 채우기 위해 자동 병합하지 않습니다. 새 근거가 확보되면 별도 검토 버전에 판단을 남긴 뒤 학습·평가 범위를 정합니다. D-MPNN 우위 비교는 이 조건을 충족한 뒤 진행합니다.
