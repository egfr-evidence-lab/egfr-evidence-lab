# 주 학습 데이터 확보 절차

2026-10-20. 22건 교육 실험 이후의 작업이다. 목표는 인간 WT EGFR의 **실험 맥락이 확인된 생화학 IC50 회귀 데이터**를 확보하는 것이다. 209건 Apsel 자료의 기존 보류 결정과 교육 실험 결과는 보존한다. 아래 기준은 모델 성능을 확인하기 전에 정하며, 최소 표본 수나 MAE를 보편적인 EGFR 합격선으로 제시하지 않는다.

| 순서 | 실행 | 판단 기준·산출물 |
|---|---|---|
| 1 | 대상·기존 보류를 고정 | WT·human·생화학 IC50. 세포·변이·Ki/Kd·분해 지표를 섞지 않음 |
| 2 | 전체 26,600건을 assay별 재집계 | 정확값·유효 구조·scaffold·최대 그룹 비율·보류 사유. Unknown 분자 유형의 구조도 검토용으로 다시 계산하되 자동 승인하지 않음 |
| 3 | 우선 후보의 원문·SI·공급사 문서 확보 | 공식 API·출판사 공개 SI·공개 특허 원문. URL·시각·형식·해시·이용 조건 기록. HTML challenge는 PDF 확보가 아님 |
| 4 | 실험 조건과 관측별 수치 대조 | 화합물 번호→record→activity→원문 표적 열, 단위·부등호·반복·구조 대조. human/WT·구성체·ATP·기질·시간·온도·검출법의 확인·결측을 구분 |
| 5 | 중복·보류·범위 판정 | 서로 다른 assay ID라도 같은 문헌·분자·표·값이면 독립 측정으로 세지 않음. 자동 감사의 오탐은 근거가 있는 새 검토 버전에서만 해소 |
| 6 | 학습·평가 가능 범위 점검 | 고유 구조·골격 수와 편중, 라벨 범위, 분할별 표본·골격·분포. 큰 단일 골격이 성능을 지배하는지와 학습곡선 설계 가능성을 검토 |
| 7 | 주 데이터 버전 고정 | 승인·보류·제외표, 원 activity ID 전체 연결, 데이터 카드·입출력 해시·분할 고정. 원문 확인과 독립 사람 검토 여부를 별도로 명시 |
| 8 | 고정된 자료로 기준 모델 실행 | 같은 분할의 Dummy·RF, seed·오차·차이 구간·실패 사례. 조건부·좁은 적용 범위를 명시하고 D-MPNN 비교 여부 결정 |

단일 assay를 우선한다. 다른 assay와 합치려면 [기존 병합 정책](../configs/cohort_policy.json)의 핵심 조건·공통 화합물·편향 검사를 통과해야 한다. 단일 assay의 결측 조건을 다른 논문이나 현재 공급사 문서만으로 추정해 채우지 않는다. 공급사 catalog 정보와 당시 실제 lot 정보는 구별한다.

## 실행 경로

첫 경로는 기존 전체 자료 안에서 구조 유형·발현 세포 문구 때문에 보류된 실험을 원문으로 재검토하는 것이다. 예를 들어 정제 단백질의 생산에 쓰인 곤충 세포는 약물 반응을 측정한 세포와 다르다. 실제 방법을 읽어 판정한다.

두 번째 경로는 미확정 큰 assay의 특허·원문 표를 확인하는 것이다. assay ID만으로 표적·조건·독립성이 같다고 가정하지 않는다. 기존에 확인한 Cot/EGFR 혼입 사례를 회귀 검사에 사용한다.

세 번째 경로는 새 공개 데이터 공급처를 검토하는 것이다. ChEMBL을 복제한 PubChem·BindingDB 기록은 독립 검증 자료가 아니며 원 논문까지 연결한다. % inhibition·Kd만 있는 대규모 자료를 IC50 회귀로 바꾸지 않는다.

Apsel SI의 이미 실패한 동일 경로는 반복하지 않는다. 실제 새 공개 경로나 사용자가 확보한 정당한 자료가 생기면 다시 검토한다. 외부 연구자에게 연락하거나 계정·유료 접근을 사용하지 않는다.

## 현재 실행 기록

후보 재집계와 원문 검토 결과는 [첫 실행 보고서](../reports/main_cohort_acquisition_ko.md)에 연결했다. 전체2,425assay 중 검토 대기242개를 정리하고, 우선7assay의787관측을 대조했다. 새45건 후보는 구조·수치 연결을 보존했지만 상세 인용 실험법과 human 종 유래 확인 전이라 `training_ready=false`이다. 단계1–5의 이번 우선 후보 검토와 단계6의 1차 진단을 실행했으며, 단계7은 후보 버전만 보존했고 단계8의 새 모델 학습은 실행하지 않았다.

확보 성공·수치 일치·과학적 승인·모델 실행은 각각 다른 상태로 기록한다. 자료가 부족하면 미확정 상태와 다음에 필요한 근거를 보고하며, 근거 없는 병합이나 승인으로 채우지 않는다.

후속으로 [원문·실제 지표·적용 범위 보고서](../reports/cohort_scope_evidence_ko.md)를 추가했다. 2019년 방법 원문은 미확보이며 OA로 연결된 자료는 ChEMBL 파생 BindingDB 데이터셋임을 확인했다. WT 특허64건은 명시된 G번호·MS로 점검 가능한35관측 중13건에 큰 차이가 있어 구조 보류를 유지했다. 자료3개의 예정 분할18개·최근접 거리234개를 계산했다. 45건의 scaffold 분할은 학습28–31·평가14–17건이고, 이웃 유사도가 최대0.986이라 새 화학 계열 일반화를 보장하지 않는다. 주 학습 승인0건·새 모델 학습0건 상태를 보존했다.
